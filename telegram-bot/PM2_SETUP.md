# PM2 Setup Guide (Windows)

## Quick Start

1. **Install PM2 globally:**
   ```bash
   npm install -g pm2
   ```

2. **Start the bot:**
   ```bash
   cd C:\Users\juned\Desktop\swap\swap\telegram-bot
   pm2 start ecosystem.config.cjs
   ```

3. **Save the PM2 process list:**
   ```bash
   pm2 save
   ```

4. **Enable auto-start on Windows boot:**
   ```bash
   pm2 startup
   ```
   Then run the command it outputs (it will give you a specific command to copy-paste).

5. **Done!** Your bot now runs 24/7. You can close CMD.

---

## PM2 Commands

### Monitor
```bash
pm2 status              # Check if bot is running
pm2 logs portalswap-bot # View live logs
pm2 monit               # Real-time monitoring dashboard
```

### Control
```bash
pm2 restart portalswap-bot  # Restart after code changes
pm2 stop portalswap-bot     # Stop the bot
pm2 start portalswap-bot    # Start the bot
pm2 delete portalswap-bot   # Remove from PM2
```

### Logs
```bash
pm2 logs portalswap-bot --lines 100  # Last 100 lines
pm2 flush                            # Clear all logs
```

## Troubleshooting

**Bot won't start:**
```bash
pm2 logs portalswap-bot --err --lines 50
```

**Check if .env is loaded:**
```bash
pm2 env 0
```

**Restart after changing .env:**
```bash
pm2 restart portalswap-bot --update-env
```
